# PodBox skills

This repository mirrors the PodBox skill bundle. The canonical copy is served by the PodBox MCP server as `podbox://skill`. This repository is the fallback for agents that cannot read MCP resources.

Start at [`podbox/index.md`](podbox/index.md).

The `podbox/` folder is synced automatically from `apps/mcp/skill` in `podbox-sh/podbox`. Do not edit it here. Changes made here will be overwritten.
