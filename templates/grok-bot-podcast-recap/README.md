# Podcast Recap (Grok Bot template)

Backup of the public Grok Bot template "Podcast Recap": a bot that turns podcast episodes into short audio recaps (narration plus real clips of the speakers), on request or for shows it watches.
Share link: https://x.ai/bot/VUCIS8sodhRjK6LBm7epy, version 3. Exported 2026-11-14.

The template links only to the make-podcast-recap skill entry. Installed copies read that skill when they make a recap, so skill updates reach them without a republish of this template.

`persona.md`, `profile.json`, `memory.json`, `routines.json`, `plugins.json`, and both files under `skills/` are the version 3 export, unchanged. This directory is not a PodBox skill: it is not served by the MCP server and it is not in the skill zips.
